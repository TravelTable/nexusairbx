# NexusRBX R15 preview model

`nexusrbx-r15-preview.glb` is a browser-runtime export of **Roblox Blocky R15 RIG v1.1** by MrXen0 (also known as Pasta).

- Original source: https://mrxen0.gumroad.com/l/xrdqsb
- Source format: Blender 4.0+
- Rig license embedded in the supplied source: free for commercial and non-commercial use; do not sell the rig or modified versions.
- The embedded Blender UI script is not included in this runtime export.

The GLB contains the 15 rigid R15 body meshes, the packed block-rig texture, and the armature required for previewing standard Roblox R15 joint motion.
