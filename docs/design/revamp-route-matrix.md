# Dark Build Ledger route matrix

This matrix records the shell, primary composition, preserved behaviour, and acceptance focus for the universal revamp.

| Route family | Shell | Target composition | Behaviour that must remain | Acceptance focus |
|---|---|---|---|---|
| `/` | Public | Active request, world cutaway, continuous build record, genre atlas, reviewed ending | Prompt handoff, analytics, metadata | No conventional SaaS hero, browser mockup, feature grid, or CTA panel |
| `/pricing` | Public | Access ledger | Plan data, billing interval, checkout URLs, subscription detection, analytics | No plan cards, recommended badge, or pill toggle |
| `/docs`, `/docs/:slug` | Public/document | Text index and document field | Content, links, metadata, code | No decorative sidebar card or terminal atmosphere |
| SEO landing routes | Public/document | Example request/output record, limits, failure/recovery, FAQ ledger | Canonicals, structured data, prompt handoff, analytics | No hero/card/FAQ-card template |
| `/downloads` | Public/document | Release ledger | Download URLs, platform and version truth | No download cards |
| `/legal`, `/legal/:slug` | Public/document | Anchored legal document | Legal text, metadata | Readable measure; no marketing treatment |
| `/ai` | Workspace | Ribbon, edge project index, request ledger, attached workbench, embedded evidence stage | Controller, runtime, Studio, plan/approval, scripts, assets, billing, focus and keyboard contracts | No ambient blobs, glass sidebar, floating stage, chat bubbles, or shrunken desktop mobile |
| `/script/:id` | Workspace | Code-led workspace context | Script loading/edit/review | Same identity as `/ai`; real code only |
| `/tools/icon-generator` | Tool | Asset desk | Generation, references, packs, publishing, billing | No mode cards or form/result card stack |
| `/assets`, `/assets/:assetId` | Tool | Contact sheet and asset record | Filters, lifecycle, moderation, Roblox ID, operations | No generic asset-card grid |
| `/icons-market`, `/icons-market/:id` | Tool/catalogue | Authored visual catalogue and licence record | Ownership, licence, selection, purchase/use flows | No generic ecommerce tile grid |
| `/settings` | Account | Text index and settings record | Save, validation, preferences, usage truth | No icon sidebar, cards, badges, or appearance selector |
| `/billing`, `/subscribe` | Account | Plan, usage, payment, and invoice ledgers | Billing and entitlement calculations, checkout | Do not repeat public pricing cards |
| `/support`, `/support/:ticketId` | Account/case | Ticket index and case record | Conversation, status, attachments, actions | No ticket cards |
| `/admin/support` | Account/operations | Dense operational records | Staff actions and permissions | No ornamental KPI row |
| `/signin`, `/signup`, `/forgot-password`, `/verify-email` | Auth | Split project record and open form column | Providers, validation, redirect, persistence | No centred form card |

## Universal verification states

Each migrated family is tested with long names, empty data, loading, errors, disabled actions, narrow width, keyboard-only input, reduced motion, increased contrast, and 200% zoom. `/ai` additionally covers disconnected Studio, blocked apply, active run, review, evidence open, and mobile Project/Request/Evidence/Workbench states.
